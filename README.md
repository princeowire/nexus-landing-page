# Nexus landing page (Next.js 15 + TypeScript + Tailwind 3 + GSAP)
npm install && npm run dev
Set the app URL: create .env.local with NEXT_PUBLIC_APP_URL=https://your-app-url (the Open Nexus buttons stay inert until set).
Structure: app/ (layout, page, globals.css) · components/ (Sections, Ticker, Fx, Reveal, AppLink, HeroTimer) · lib/content.ts (FAQ, steps, APP_URL).
